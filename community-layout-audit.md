# Community Layout Audit

The supplied Android screenshots confirm that the existing community cards keep too many independent controls in the first visible block. Creator name and timestamp run together, while the secondary creator controls appear as a single unwrapped text string. The action strip wraps into several lines and the audience label becomes a separate low-priority block, making a single post visually tall and difficult to scan.

Attached-content cards currently repeat generic marketplace metadata without a visible audio affordance or cover treatment. Video renders as a native browser player with oversized controls rather than a deliberate, bounded media surface. The implementation will preserve all existing actions but use a concise creator header, overflow action menu, compact engagement strip, and bounded media cards that show their content type and playback control clearly.

The approved adjustment is corrective rather than a redesign: retain BeatBox dark/gold branding, feed order, story rail, composer, discovery, privacy state, and bottom navigation while prioritizing readable mobile spacing and progressive disclosure.
