# PWA Adoption Interface Validation

## Responsive visual check

The homepage was reviewed at desktop (1280×720) and mobile (375×812) viewports after adding the PWA adoption controls.

| Viewport | Observation | Result |
|---|---|---|
| Desktop | The install card appears immediately below the primary home-page calls to action. Its install action and dismissal control are visible without obscuring the hero content. | Pass |
| Mobile | The install card reflows into a compact two-row card below the primary actions. Its browser-guidance fallback remains readable, and the dismiss control retains a clear touch target. | Pass |

The mobile full-page review confirms that the rating prompt follows the install card directly in the hero area. When a public Play Store listing URL is not configured, it truthfully communicates that reviews will be available after the official listing launches rather than sending visitors to a fabricated listing.
